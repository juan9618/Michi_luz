# 🐱 MICHI LUZ

## Velas con intención 🕯️

Michi Luz es un sitio web creado para presentar un emprendimiento de velas artesanales. El proyecto busca mostrar los productos de una manera sencilla, agradable y fácil de navegar.

La página utiliza **HTML, CSS y JavaScript**, incorporando Flexbox y CSS Grid para organizar los diferentes elementos del sitio.

## 📋 Contenido del proyecto

El sitio cuenta actualmente con las siguientes páginas:

* **Inicio:** Presentación de Michi Luz y una introducción a los productos.
* **Productos:** Muestra las categorías disponibles.
* **Velas Aromatizadas:** Presenta las velas, sus aromas, formas y precios.
* **Wax Melts:** Muestra los diferentes Wax Melts disponibles.
* **Velas de Chocolate:** Presenta los productos de esta categoría.
* **Quiénes Somos:** Explica brevemente qué es Michi Luz.
* **Comunicación:** Contiene los datos de contacto del emprendimiento.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid

## 🎨 Diseño

El diseño utiliza principalmente los colores amarillo, blanco y negro, buscando transmitir una apariencia sencilla y relacionada con la identidad de Michi Luz.

Se utiliza **Flexbox** para organizar elementos como el encabezado y el menú de navegación, mientras que **CSS Grid** se utiliza principalmente para organizar las tarjetas de productos.

Además, el sitio cuenta con diseño responsive para adaptarse a diferentes tamaños de pantalla.

## ⚙️ JavaScript

El proyecto cuenta con un archivo `script.js` que permite realizar funciones relacionadas con los precios de los productos y también muestra un mensaje en la consola cuando el sitio se carga correctamente.

## 🚀 Ejecución

Para visualizar el proyecto solamente es necesario abrir `index.html` en un navegador.

También se puede utilizar **Visual Studio Code** junto con una extensión como Live Server para visualizar los cambios en tiempo real.

## 📌 Estado del proyecto

Actualmente el sitio cuenta con las páginas principales del emprendimiento y la presentación de sus productos.

El proyecto continuará desarrollándose con nuevas secciones y funcionalidades.
